# 시연 영상 + 책 띠 세로 휠 — 설계

- 첫 화면 책 띠: 띠 위 세로 휠 → 가로로 넘김 (페이지 스크롤은 띠 밖에서만).
- 시연 영상: 9:16 1080×1920, 약 40초, 사용자가 준 힙합 곡의 박자에 맞춘 컷·모션.
  흐름: 로고 → 해독 서점 데미안 → 알라딘 구매 완료 카드 → 데미안.pdf 업로드 → 서재 →
  친구 초대·합류 → 리더 프레즌스·레이스·문장 공유 → 기능 몽타주 → 아웃트로.
- 제작: 로컬 앱 + 친구 계정 2개 + 헤세 원문 번역 PDF로 실제 화면 촬영 →
  HTML 모션 타임라인 프레임 렌더(30fps) → ffmpeg 합성. 결과물은 저장소 밖(~/Desktop/인프).
- 추가 기능 후보: 스포일러 잠금 메모, 완독 카드, 추월 알림, 함께 읽기 일정, 페이지 반응, 카톡 초대 미리보기.
