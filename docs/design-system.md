- 한때 다른 방향(Index·Paper)을 시도했지만, 팀 결정으로 이 시안으로 돌아왔어요 ([결정 로그](../.grill/ui-rebuild-glass.md)).
- **Figma:** [MVP Screens](https://www.figma.com/design/mp2nKNmBdJ7Dg2rc2p9rht) — 페이지 **Glass v2**(홈·검색·리더 3화면. 읽기방·레이스·리그는 Figma MCP Starter 플랜 호출 한도로 미반영), **MVP Screens**(v1 플랫, 보관용)

v1은 Apple 웹의 플랫한 타일 구조를 그대로 옮겼습니다. v2는 같은 절제된 타이포그래피와 단일 액센트 원칙을 유지하되,
**사진 같은 배경 위에 떠 있는 유리 패널**로 표면을 바꿔 "책을 펼친 조용한 장소" 같은 분위기를 만듭니다.

## 원칙

1. **배경은 사진, UI는 유리.** 흐린 하늘과 초원이 흐릿하게 깔린 배경 위에 반투명 패널이 떠 있다. 패널은 배경을 흐리게 비추되 가리지 않는다.
2. **글은 읽혀야 한다.** 장문 독서(리더)는 불투명도 78%의 서리 유리 시트 위 잉크색 텍스트. 그 외 짧은 텍스트만 흰 글씨.
3. **액션은 흰 알약.** 주요 버튼은 92% 흰색 필 + 잉크 텍스트. 보조 버튼은 유리 필. 카카오 버튼만 브랜드 노랑 예외.
4. **빛은 위에서.** 모든 유리는 윗면 1px 하이라이트(inner shadow)와 대각선 반사 그라디언트 테두리를 가진다.
5. **분위기 전환 = 시간대 전환.** 경쟁(레이스) 화면만 밤 하늘 배경 — 몰입 모드 신호.
6. **스포일러는 잠금 칩.** 잠긴 반응은 내용 없이 개수만, 어두운 유리 칩으로.

## 재질 (Material)

| 재질 | 구성 | 용도 |
|---|---|---|
| `glass/regular` | 흰색 16% + 대각선 흰 그라디언트(22%→2%) · 배경 블러 30 · 테두리 1px 대각 그라디언트(75%→15%→40%) · 윗면 inner shadow 55% · 드롭섀도 y18 r40 14% | 카드, 입력, 탭바 |

| `glass/dark` | 잉크 72% · 배경 블러 20 · 흰 테두리 25% | 스포일러 가드 칩 |

## 배경 (Photo backdrop)

그라디언트와 블러된 타원 레이어를 겹쳐 만든 합성 배경입니다(외부 이미지 없음 → 라이선스 문제 없음).

| 레이어 | 낮 | 밤 |
|---|---|---|
| 하늘 | `#6f767f` → `#9ea3a9` → `#c9c7bf` | `#0b1020` → `#1b2336` → `#2a2f3a` |
| 광원 | 흰색 방사형 95%, 블러 30 | 달빛 35% + 별 |
| 초원 | `#2e4426` · `#3c5530` · `#55703f` 타원, 블러 40–50 | 채도 낮춘 동일 구성 |
| 꽃 보케 | 크림색 `#f1efe6` 80% · 노랑 `#e8c35a` 70%, 블러 6–18 | 투명도 20–25% |

실제 앱에서는 동일한 구성을 CSS `radial-gradient` + `filter: blur()` 레이어 또는 사전 렌더링한 WebP로 구현합니다.

## 컴포넌트 (Figma 노드 이름)

## 구현 가이드 (웹)

```css
.glass {
  background:
    linear-gradient(135deg, rgb(255 255 255 / .22), rgb(255 255 255 / .02)),
    rgb(255 255 255 / .16);
  backdrop-filter: blur(30px) saturate(160%);
  border: 1px solid rgb(255 255 255 / .35);
  box-shadow: inset 0 1px 0 rgb(255 255 255 / .55), 0 18px 40px rgb(0 0 0 / .14);
  border-radius: 28px;
}
```

`backdrop-filter` 미지원 환경에서는 흐림 대신 어두운 반투명 면(`rgb(60 66 74 / .72)`)을 깔아 흰 글씨 대비를 지킵니다.

| 리더 `/books/{id}/read` | 유리 상단바(‹ 제목 · 가 · %) + 종이 시트(러닝헤드 · 드롭캡 · 명조 · 쪽번호 · 문단 메모 · "○○님이 이 쪽을 함께 읽고 있어요") · 잠김 알약 · 반응/설정 바텀 시트 | #3 |
| 읽기방 `/rooms/{id}` | 카카오 노랑 초대 버튼(휴대폰 공유 시트 → 링크 복사) · 멤버 진행률 · 최근 반응(잠김 알약) | #4 |
| 레이스 `/battles/{id}` | 밤 배경 · 남은 시간 · 우리 팀 vs 상대 점수 · 줄다리기 바 · 팀 기여 · 이어 읽기 버튼 | #5 |

## 모션

[app/web/static/css/motion.css](../app/web/static/css/motion.css) · 근거는 [조사 문서](research/advanced-web-2026.md).

| 토큰 | 값 | 용도 |
|---|---|---|
| `--spring-smooth` | 감쇠비 1, 넘침 없음 | 시트 · 페이지 (350~450ms) |
| `--spring-ios` | 감쇠비 0.82, 1% 넘침 | 기본 (450~550ms) |
| `--spring-bouncy` | 감쇠비 0.55, 12% 넘침 | 탭 알약 · 배지 · 이모지 (700ms 안팎) |

- **움직이는 것은 화면 내용(`.scroll`)뿐** — 폰 프레임·배경·탭 바는 그대로 있고, 켜진 탭의 흰 알약만 새 탭으로 미끄러진다. 유리 요소에 전환 이름을 따로 주면 스냅샷에서 흐림이 빠져 흰 상자로 보이므로 주지 않는다.
- 같은 대상은 화면을 넘어 이어진다: 책 제목(`title-{id}`) · 표지(`cover-{id}`) · 방 이름(`room-{id}`).
- 누르면 `scale(.95~.975)`로 80ms, 놓으면 스프링으로 복귀. 진행 막대는 0에서 차오르고, 점수·포인트는 카운트업.
- transform · opacity만 움직인다. 실제 흐림(`backdrop-filter`)과 굴절은 표면 2~3곳만.
- `prefers-reduced-motion: reduce`이면 모든 움직임을 끄고 페이드만 남긴다(내용은 처음부터 보임 — `tools/browser_check.py`로 확인).

## 접근성

- 유리 위 흰 텍스트는 배경의 가장 밝은 영역(광원·꽃 보케) 위에 두지 않는다 — 콘텐츠는 상단 60% 구간에 배치.
- 장문은 반드시 `glass/frosted`(대비 AA 이상).
- 터치 타깃 44px 이상, 이모지 단독 의미 전달 금지.
- `prefers-reduced-transparency` 사용자에게는 불투명 표면으로 대체.
- 밝은 하늘 위 흰 글씨에는 아주 옅은 그림자(`0 1px 2px / .16`)를 깐다. 리더 본문은 종이 시트 위 잉크색(#2a251f, 대비 AAA).
