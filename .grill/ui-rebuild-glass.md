# Grill: UI 재구성 — 처음 시안(Glass v2) 기반
Date: 2026-10-20

## Intent
Index(색인) 디자인을 버리고, 처음 만들어 둔 시안처럼 "친구와 함께 읽는 폰 앱" 느낌으로 화면을 다시 만든다.

## Constraints
- 시안을 그대로 재현한다(색·폰트·간격·문구). 시안에 없는 화면만 같은 언어로 새로 만든다.
- 폰 우선. PC에서는 가운데에 폰 크기 화면(390×844 프레임)으로 보여 준다 — 노트북 시연용.
- 백엔드 기능·API는 그대로 둔다. 바꾸는 건 화면(templates·CSS·JS)과 화면용 데이터 정리뿐.

## Key decisions
- Decision: 앱 전체를 시안 A(Glass v2)로 — 흐린 사진 배경, 유리 카드, 흰 알약 버튼, 떠 있는 유리 탭바(홈·검색·읽기방·리그), 컬러 동그라미 아바타. Reason: 사용자 선택("유리 기본"). Alternative considered: 종이 기본 + 경쟁만 밤하늘, 종이 기본 + 유리 요소 차용.
- Decision: 리더는 시안 A의 리더 그대로 — 유리 상단바 + 아이보리 종이색 본문 시트(명조, 러닝헤드, 쪽번호, 반응은 왼쪽 선 인용). Reason: 사용자 선택. Alternative considered: 시안 B의 종이 페이지(리본·손글씨 메모).
- Decision: 레이스·배틀은 밤하늘(night) 배경. Reason: 시안 A의 '경쟁 모드' 신호.
- Decision: 시안에 없는 화면(로그인·가입·책 상세·읽기방 목록·초대 미리보기·팀·내 정보·오류)은 같은 유리 언어로, 한 화면에 카드 2~3개만. Reason: 사용자가 "정보가 너무 많고 어지럽다"고 함.

## Surfaced assumptions
- Index에서 싫었던 점: 웹페이지 같음, 툭박하고 삭막함, 친구 느낌 없음, 정보 과다. → 하단 탭바·둥근 유리·아바타·짧은 문장으로 해결한다.
- 카카오톡 공유 SDK 키가 없으므로 노란 "카카오톡으로 친구 초대" 버튼은 휴대폰 공유 시트(Web Share) → 안 되면 링크 복사로 동작한다.

## Out of scope
- 시안 B(종이 서재) 요소, 테마 전환 기능, 백엔드 규칙 변경.
